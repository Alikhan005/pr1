# Six Sense Agency Website

## Overview

Website for Six Sense, a student PR and media agency created as part of a university project.

The website presents the agency, team members, media content and project activities in a modern responsive interface.

## Features

* Responsive design
* Team showcase
* Agency information pages
* Video section
* Smooth navigation
* Modern UI

## Technologies

* HTML5
* CSS3
* JavaScript

## Project Structure

* `index.html` – main page
* `agency.html` – agency information
* `team.html` – team section
* `videos.html` – video gallery
* `styles.css` – styling
* `script.js` – interactive functionality
